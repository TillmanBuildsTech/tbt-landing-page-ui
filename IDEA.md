# tbt-landing-page-ui

Build a throwback-style landing page UI kit with retro terminal aesthetics for quick personal project launches.

- Curate a reusable component set: hero, nav, footer, project cards, and a blinking-cursor command-line panel.
- Ensure fully responsive, keyboard-navigable, and accessible markup with semantic HTML.
- Deliver a live demo page showcasing all components with a nostalgic CRT scanline effect toggle.
- Include a lightweight style guide documenting color palette, type scale, and spacing tokens.
- Provide copy-paste ready HTML/CSS/JS snippets for non-framework use.
